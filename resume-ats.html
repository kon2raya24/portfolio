LLM-Friendly Wiki (Karpathy-style Obsidian Vault) — Enterprise WMS Codebase

Hand-maintained Markdown knowledge base documenting a large enterprise WMS codebase, designed so human engineers and AI coding agents share the same context. Autonomous AI Engineer (Multi-LLM Agent Pipeline) — Enterprise Ticketing

Production multi-LLM autonomous AI engineer wired into a real Laravel 11 ticketing system. php artisan ai:work {ref} picks up tickets in ASSIGNED board status, auto-detects the target repository from a systems mapping table, dispatches to the operator-chosen brain (Claude, Gemini, OpenAI, OpenRouter, Qwen), persists per-ticket conversation in AIChatMemory, and writes a session record.
